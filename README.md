# AI control-mapping assistant

> A retrieval-augmented assistant that maps evidence to controls, with citations, human review, and measured accuracy.

**Status:** 🚧 In progress

## What it does
Given a config export or policy excerpt, suggests which NIST 800-53 / FedRAMP controls it satisfies, cites the source text, and drafts implementation statements for human approval. Includes a hand-labeled evaluation set and reported accuracy and hallucination rates.

## Frameworks and controls
NIST 800-53 Rev 5, FedRAMP baselines, NIST AI RMF

## Stack
Python, embeddings + vector store, LLM API, evaluation harness
